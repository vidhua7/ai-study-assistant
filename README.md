
# AI Study Assistant

An AI-powered study application built with Python, Streamlit, and Google's Gemini API.

## Features

- Upload PDF study materials
- Ask questions about uploaded notes
- Generate exam-oriented notes
- Create quick revision sheets
- Generate interactive multiple-choice quizzes
- Check answers and track quiz scores

## Requirements

- Python 3.10 or later
- A Gemini API key from Google AI Studio

## Installation

Clone the repository and enter the project directory:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Set your Gemini API key in PowerShell:

```powershell
$env:GEMINI_API_KEY="YOUR_API_KEY"
```

Run the application:

```bash
python -m streamlit run app.py
```
